# Protein Letters

Write words with shapes made from protein structures. Choose **Change** under a letter to use a different view. Some shapes are assembled from whole protein pieces.

This site runs in the browser using static files. Serve this folder with any static web server, or choose **Settings → Pages → Deploy from a branch → main → /(root)** on GitHub.

## Structure sources

Images are renderings of public Protein Data Bank structures. Assembled letters use 2WCD chain G. Original structure authors and citations are listed on each entry. See the [RCSB PDB usage policy](https://www.rcsb.org/pages/usage-policy).
